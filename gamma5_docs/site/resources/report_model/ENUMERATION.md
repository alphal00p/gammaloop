# One-loop 1PI diagram enumeration (HepKIT, model sm_unbroken_bmhv.json)

Generated by `enumerate_diagrams.py` + `merge_and_report.py`. Machine-readable data: `enumeration.json`; one DOT file per component diagram under `dot/<class>/<assignment>/`.

**Reading the tables.** A *component diagram* is a HepKIT diagram for fixed SU(2) components of the external legs (colour is native, so `G` is one field). Component tuples: all doublet components, and SU(2)-adjoint indices up to relabelling of the values 1,2,3 (see README). A *multiplet-level diagram* is the one-loop cycle with internal lines replaced by their multiplet (Q1,Q2 -> Q; W1,W2,W3 -> W; ghW* -> cW; H1,H2 -> H) and external legs labelled by position; it is the union over component tuples. *Labelled* counts treat identical external legs as distinguishable (what one sums in a Green function); *unlabelled* counts identify diagrams related by permuting identical external legs ('+ crossed'). Arrow `>`/`<` gives the particle flow of a complex line along the reading direction of the loop word.

Topology names: *fermion/scalar/gauge/ghost loop* = all loop lines of that kind; *snail/seagull* = one vertex with a closed line (quartic or Yukawa-free seagull); mixed names list the kinds of loop lines (e.g. *fermion-gauge loop* = gauge exchange on an open fermion line). For Delta insertions: *[ext ghost at Delta]* = the external ghost sits on the Delta vertex; *[Delta ghost internal]* = the Delta ghost is a loop line (internal-ghost diagram).

Signs: `overall_factor` in enumeration.json is HepKIT's. In the commuting ghost encoding a closed ghost loop lacks its -1, recorded as `hand_closed_ghost_loop_sign = -1`; ordering signs of ghost and source legs are not meaningful in this encoding (README).
