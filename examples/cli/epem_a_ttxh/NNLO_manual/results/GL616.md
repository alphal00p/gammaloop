## Routing and singular loci

GL616 has four loops and no `V_36` or `V_37`, hence no applicable mandatory
hard-collinear sector. With `a=K0`, `b=K1`, `c=K2`, `d=K3`, and zero
incoming spatial momentum sum, the raw routing is

```text
e2  = b-a             H
e3  = a               t, lmb_id 0
e4  = b               t, lmb_id 1
e5  = d               t
e6  = b+d-a           t
e7  = c               t, lmb_id 2
e8  = c               t
e10 = d               t, lmb_id 3
e11 = P0+P1           a, fixed spatial momentum 0
e12 = b+d-c           t
e13 = b-c             g = q13
e14 = b+d-a-c         g = q14
```

The q13 and q14 constraints are independent and have rank 3 each; their
common double-soft locus has rank 6. For `Et(k)=sqrt(|k|^2+173^2)`, the
process-active equations are

```text
eta5  = 2 Et(d)-1000
eta13 = Et(b)+Et(d)+Et(c)+Et(b+d-c)-1000
eta23 = Et(a)+Et(b+d-a)+Et(c)+Et(b+d-c)-1000
eta25 = Et(b+d-a)+Et(c)+|q14|-1000
eta28 = 2 Et(c)-1000
eta52 = Et(b)+Et(c)+Et(d)+Et(b+d-c)-1000
eta57 = Et(d)+Et(b+d-c)+|q13|-1000
eta58 = Et(a)+Et(d)+|q13|+|q14|-1000
eta62 = Et(b)+Et(b+d-a)+|q13|+|q14|-1000
eta66 = Et(b)+Et(c)+|q13|-1000.
```

E13 and E52 are distinct E-surface instances with the same numerical
equation. Structurally coincident inactive surfaces were retained in target
distance series wherever a chosen locus necessarily approached them; no
unlisted soft or active threshold locus was silently introduced.
