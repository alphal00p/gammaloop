## Directive and precision diagnosis

The complete all-orientation threshold-on evaluation passes both single-soft directions and all four intersections of one soft direction with an active surface. The only unresolved correlated direction is the rank-6 double-soft/E20/E52 intersection. Disabling threshold subtraction on that exact point and axis changes none of the fitted powers materially: the threshold-on/off values agree to the displayed precision while both retain poor `R2` and strong branch/window variation.

Therefore the unresolved behavior is generic f64 cancellation loss, not demonstrated threshold-counterterm damage. The prerequisite for an Arb adjudication---a smooth, branch-consistent f64 failure materially restored by threshold-off---is absent. No Arb run or speculative projection is accepted. The clean DOT consequently remains without an explicit `threshold_counterterms` document. Because no association was edited, an edited-association threshold-only validation is not applicable; threshold subtraction nevertheless remains enabled in generation and integration.
