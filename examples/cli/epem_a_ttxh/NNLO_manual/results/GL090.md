## Directive and precision diagnosis

The exact `e13` comparisons show material threshold sensitivity: removing threshold subtraction changes the generic and both correlated `e13` envelopes from roughly `p=3..5` with poor fits to smooth `p=1` passes. This demonstrates that the f64 cancellation problem involves threshold-counterterm contributions, but it does not yet identify a physical non-integrable singularity or a justified projected association.

Campaign methodology permits an Arb adjudication only when the same threshold-on path is first a smooth, branch-consistent f64 failure and threshold-off materially cures it. Here the second condition holds but the first does not. Consequently no Arb run, per-cut projection, or graph edit is accepted within the lease; guessing a directive from noisy cancellation would violate the precision gate. The unresolved threshold-sensitive evidence is preserved rather than mislabeled as safe. The clean DOT retains no explicit `threshold_counterterms` document, and an edited-association threshold-only check is therefore not applicable. Threshold subtraction remains enabled in the integration.
