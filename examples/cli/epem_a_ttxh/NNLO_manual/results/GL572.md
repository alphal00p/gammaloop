## The invalid-degenerate-geometry diagnosis

The original problematic path imposed `c=d=0` while forcing several massive
threshold equations at the origin. Both f64 and Arb then rejected a radial
solution before producing a complete JSON. This is an overlap-center/radial
root degeneracy of the chosen point; it is not a sampled divergent integrand.
Changing the CT structure to make that point evaluable would therefore fit an
invalid diagnostic.

A nondegenerate simultaneous solution was constructed instead:

```text
a = (-122.320469248357, -134.388631996564, -124.183902003017)
b = (-212.410639726654,  192.993363941342,  232.608677716832)
c = d = (128.143920640021, 135.728643631826, 116.623814140209)
axis da = (211,-157,193), db = dc = 0, dd = (98,-86,342)
```

At its midpoint, `E6/E44/E45/E63` vanish, `E9=E10=-440.0956`,
`E13=+533.5625`, and `|q13|=440.0956`. Thus the targeted family is isolated
from the other active surfaces, `q13` is safely nonzero, and all four target
distances have nonzero one-sided linear slopes. The original pristine state
evaluates this path with an active CT and the clean `p≈2` fit shown above.

## UV profile

The final pristine state was checked with threshold subtraction enabled,
all generated orientations, every nonempty derived-LMB subset, and four fixed
rays aligned with distinct directions of the original `(e3,e4,e6,e7)` basis.
The focused screen uses nine exponent points over `8..12`, seed
`57220260809`, ray norms 1000, and three worker threads. That old binary's UV
API did not expose an LMB/subset filter; reducing points and fixing rays was
the narrowest available test without silently dropping a UV limit.

The old-binary profile remained compute-bound until its 720-second process
watchdog. The guarded wrapper ended after 752.253 s including signal grace,
with `exit_reason="timeout"`, return code `-15`, peak recursive RSS
4,191,088,640 bytes, and at least 442,679,820,288 bytes free disk. GammaLoop
serializes `uv_profile.json` only on normal completion; no requested output
directory or partial JSON exists. Consequently there is no defensible slope,
coverage, subwindow-drift, or precision-escalation decision. UV certification
is **inconclusive**, not failed. The process tree was verified gone.

The selector-enabled rebuild was then used to intersect graph `0`, pristine
generation LMB `0` `(e3,e4,e6,e7)`, masks `1/2/4/5/8/12/15`, and
cardinalities `1/2/4`, retaining all 532 orientations. The nine-point combined
