
## Directive and precision diagnosis

Threshold subtraction is active in the approach evidence through `additional_contribution_sums.threshold_counterterm_0`. On both coalescing double-soft families, disabling it on the exact same path changes none of the displayed powers materially: threshold-on and threshold-off fits agree while retaining low `R2`, wide envelopes, and branch disagreement. The behavior is therefore consistent with generic f64 cancellation loss rather than demonstrated threshold-counterterm damage.

The required Arb gate---a smooth branch-consistent f64 failure materially cured by threshold-off---is not met. No Arb run or speculative projection is accepted, and the clean DOT retains no explicit `threshold_counterterms` document. Because no association was edited, an edited-association threshold-only check is not applicable. Threshold subtraction remains enabled for the final integration.
