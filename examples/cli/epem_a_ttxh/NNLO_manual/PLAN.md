### Limit construction

- Use the raw diagnostic DOT’s `lmb_rep` and generated cut metadata to express each edge as \(q_e=A_eK+b_e(P)\). The committed DOT remains clean.
- Enumerate limits only from process-valid cuts:

  - every independent single-soft massless edge;
  - every independent double-soft subset;
  - for the 14 `V_36` graphs, every hard, nonzero gluon-collinear set appearing in a valid cut;
  - every correlated soft/threshold intersection where threshold CTs can spoil LU cancellation;
  - a threshold-only, IR-away path for every explicitly edited association.

- `profile bulk` may seed or cross-check limit enumeration, but final evidence must use explicit `approach` commands in the card.
- All graphs have four loops, so momentum-space midpoints and axes have 12 components.
- Construct paths as follows:

  - Soft: solve \(q_e(K_\star)=0\), retain a generic hard complement, and choose \(dK\) so \(q_e(K_\star+\lambda dK)=\lambda v_e\).
  - Double-soft: solve both independent soft momenta and use independent generic directions.
  - Collinear: choose nonzero positive energy fractions on a common direction and perturb only independent transverse relative directions.
  - Correlated soft/threshold: impose the soft constraints and relevant \(\eta=0\) equations at the midpoint, then choose a non-tangent axis for which every target \(|q|\) and \(|\eta|\) vanishes linearly.
  - Reject paths that accidentally approach an unlisted soft, collinear, or threshold locus.

- Every accepted approach uses the complete graph sum:

```text
--momentum-space --graph-id 0
--n-points 50 --logarithmic
--min-abs-t 1e-6 --max-abs-t 1e-2
--skip-midpoint --n-cores 3
```

With no orientation ID, GammaLoop sums all generated orientations; all process-valid cuts also remain active.

### Fit and directive diagnosis

- Fit the complex norm \(|I|\) separately on positive and negative branches, reporting \(p=-d\log|I|/d\log|\lambda|\).
- Use the closest 8, 12, and 16 finite nonzero points on each branch. Every fit must have \(R^2\ge0.995\), the fitted-\(p\) envelope must span at most 0.5, and all target kinematic distances must scale with slope \(1\pm0.05\).
- Compute the IR constraint rank \(r\) numerically:

  - normally \(r=3\) for one soft momentum;
  - \(r=6\) for two independent soft momenta;
  - \(r=2\) per independent hard-collinear transverse relation.

  Correlated threshold equations do not enlarge the IR phase-space measure rank.

- Classification:

  - pass if the complete \(p\) envelope satisfies \(p\le r-0.25\);
  - fail if it satisfies \(p\ge r+0.25\);
  - otherwise inconclusive;
  - any nonfinite data, poor fit, branch disagreement, or incorrect target scaling is inconclusive.

- Threshold-only paths must remain finite on both branches, with no growth stronger than \(p=0.25\), and must show an active threshold CT contribution. Threshold-off comparisons are diagnostic only.
- Begin with no explicit directive. If a correlated IR failure disappears with threshold subtraction disabled, diagnose per-cut and per-CT approach components.
- First remedy: place every coalescing CT required for LU cancellation in the smallest common valid projected subspace excluding the soft coordinate, following GL297.
- Only when distinct one-loop and two-loop deformation regions genuinely coexist, create independent named variants with complementary squared-\(\eta\) weights, following the GL638 construction. Treat every projected variant as its own E-surface instance.
- Multiplier expressions use the established syntax `eta(star, eset(...))`; do not introduce `effective` or unwrapped edge lists. Do not disable all variants or remove threshold subtraction as a cure.
- After every DOT edit, regenerate from a clean assigned state and rerun all previously defined limits plus threshold-only checks.
- GL297 and GL638 are pilots, not assumed globally solved: their existing directives were demonstrated only for selected orientations/cuts and must be revalidated across every generated orientation and process-valid cut.

### Scientific objective

The objective is not merely to classify troublesome graphs. For every graph that is not
fully closed, determine the correct graph-level `threshold_counterterms` metadata that
retains proper local threshold subtraction and makes every physical soft,
double-soft, and applicable collinear limit integrable. The admissible metadata search
includes complete coalescing threshold families, named variants, ordered `subspace`
bases, explicit `parent_lmb` disambiguation, and smooth complementary multipliers when
genuinely distinct deformation regions require them. Threshold-off results, disabled
counterterms, epsilon regulators, late exact-zero gates, or an edit that merely hides a
bad contribution are diagnostics or rejected candidates, never cures.

Use component decomposition and corrected nondegenerate limit geometry to identify the
causal threshold association. Start from the smallest shared projected topology in the
GL297 sense. If that cannot cover two genuinely different one-/two-loop regions, test a
GL638-style complementary squared-eta partition and explicitly audit its joint-zero
behavior. Apply a directive to every association needed for the cancellation, not only
the first surface whose aggregate label appears singular. Regenerate cleanly after each
candidate and reject it if the evaluator/association inventory changes unexpectedly, a
previously safe limit regresses, or center/radial-root construction becomes invalid.

### Loop-momentum basis is an allowed structural variable

The four generation `lmb_id` assignments in a DOT graph may be moved to another
topology-valid independent edge basis whenever that provides the required nonsingular
parent embedding or removes a genuine center/radial-root obstruction. This is part of
the cure space, not a last-resort formatting change. For every proposed remap:

1. prove that the new four edges form a valid independent basis and record the old/new
   momentum transformation;
2. transform every `approach` midpoint, axis, fixed UV ray, and inspected integration
   coordinate exactly before comparing with the old basis;
3. verify that all process-valid cuts, orientations, evaluators, and threshold
   associations remain present;
4. rerun the complete IR regression, every edited IR-away threshold-only crossing, the
   final tailored per-orientation UV profile, and any integration checkpoint used for
   acceptance.

A basis change that only changes how a failing path is parameterized, or causes an
assigned threshold to canonicalize away, must be rejected and the last accepted basis
restored.

### Mandatory adaptive UV profiling

structure. The coordinator-added generic selectors are:

- `--graph-index`: retain specified zero-based generated graph indices;
- `--lmb-index`: retain specified zero-based generated LMB indices;
- `--loop-subset-mask`: retain specified nonzero bit masks of active LMB coordinates;
- `--subset-cardinality`: retain subsets with the specified numbers of coordinates.

Selectors of different kinds intersect; comma-separated values of one kind form a
union; no selector preserves the legacy exhaustive profile. Serialized graph/LMB

options to profile only the UV limits supported by the graph's soft/threshold momentum
