# Archived command-card notes

This directory is historical material from an older GammaLoop command layout. The command cards
named by the former manual are no longer present, and its `./bin/gammaloop` invocations and
settings examples must not be treated as current syntax.

For maintained workflows, use the canonical
[first-state tutorial](https://alphal00p.github.io/gammaloop/products/gammaloop/latest/tutorial/),
[process-generation and workspace guide](https://alphal00p.github.io/gammaloop/products/gammaloop/latest/guides/process-generation/),
and the repository's [registered example contracts](../../../docs/examples.toml). The generated CLI/settings
reference on the documentation site is authoritative for the selected revision.

The remaining files under `examples/OLD/` are retained only to preserve development history and
may be useful when interpreting old states or commits. Port an example to a current run card and
register its verification contract before presenting it as supported documentation.
