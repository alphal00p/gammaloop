# Python API snapshots

These files are deterministic documentation inputs for the Python surfaces that
are registered by the workspace's PyO3 extension modules. All five snapshots
are emitted from isolated `pyo3-stub-gen::StubInfo` inventories so annotations
from one extension cannot leak into another.

`gammaloop-python.pyi` describes `_gammaloop`'s explicit
`register_python_api` surface. Its isolated exporter registers the real
extension objects into a fresh module and compares the inventory's exports,
class members, callable parameters, and visible defaults with that runtime.

The graph, tensor, HEPKit, and Vakint interfaces are Symbolica community modules.
Idenso's Python operations belong to the shared `symbolica.community.tensor`
surface. Follow the [repository contribution guidance](../../../CONTRIBUTING.typ).

Regenerate each inventory in a separate Cargo invocation:

```sh
cargo run --locked -p alphal00p-docs-python-exporter --features gammaloop -- \
  gammaloop-python docs/api/python/gammaloop-python.pyi
cargo run --locked -p alphal00p-docs-python-exporter --features linnet -- \
  linnet-graph docs/api/python/linnet-graph.pyi
cargo run --locked -p alphal00p-docs-python-exporter --features spenso -- \
  spynso3 docs/api/python/spynso3.pyi
cargo run --locked -p alphal00p-docs-python-exporter --features feynkit -- \
  feynkit-community docs/api/python/feynkit-community.pyi
cargo run --locked -p alphal00p-docs-python-exporter --features vakint -- \
  vakint-community docs/api/python/vakint-community.pyi
```

Append `--check` to any command to compare the generated bytes with the checked
snapshot without rewriting it. `just docs-check` and Nix CI do this for all five
isolated inventories. Graph, HEPKit, GammaLoop, and Vakint exports are compared
with fresh runtime registration. Tensor exports are checked against their shared
production surface declaration.

The Linnet invocation renders one canonical StubInfo surface, including its
deterministic `__all__`, and writes or checks both
`crates/linnet-py/python/symbolica/community/graph/__init__.pyi` and
`docs/api/python/linnet-graph.pyi`. HEPKit likewise shares the native package stub
at `crates/feynkit-py/python/symbolica/community/hepkit/__init__.pyi`.

Do not combine the inventory features: PyO3 stub registration uses a
process-wide inventory. GammaLoop's additional callable-signature acceptance
test can be run with:

```sh
cargo test --locked -p alphal00p-docs-python-exporter --features gammaloop \
  gammaloop_runtime_surface_and_signatures_match_the_docs_stub
```
