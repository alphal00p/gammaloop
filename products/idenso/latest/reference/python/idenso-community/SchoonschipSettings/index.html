SchoonschipSettings

SchoonschipSettings(*, depth_limit: Optional[int] = 1, mode: Optional[SchoonschipMode] = None, traversal: Optional[SchoonschipTraversal] = None, expand_contracted_sums: bool = False, simplify_chain_like_functions: bool = False, schoonschip_rank1_tensors: bool = True, contraction_order: Optional[SchoonschipContractionOrder] = None)

Immutable configuration for expression and network Schoonschip passes.

Constructor

#

Configure traversal, depth, shorthand expansion, and network-contraction policies.

depth_limit=None removes the recursion-depth limit. traversal is ignored in SinglePass mode. mode=None, traversal=None, and contraction_order=None select Recursive, BreadthFirst, and SmallestDegree, respectively.
