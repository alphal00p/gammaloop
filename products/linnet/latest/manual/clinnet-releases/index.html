Clinnet release history

Clinnet is versioned independently from the Linnet library. Its canonical history remains the Clinnet changelog source. This rendered copy makes that history part of the manual, navigation, search, and product PDF.

All notable changes to this project will be documented in this file.

The format is based on Keep a Changelog, and this project adheres to Semantic Versioning.
