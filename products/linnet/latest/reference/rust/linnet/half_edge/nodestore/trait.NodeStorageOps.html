Expand description

Defines a comprehensive set of operations for a node storage backend within a HedgeGraph.

This trait extends NodeStorage by adding methods for modifying the storage (e.g., extending, extracting, deleting, identifying nodes), building it, iterating over nodes, and mapping node data. It abstracts over the specific data structures used to store node information and their incident half-edges.

Moves the selected half-edges into a new store and removes them from self.

split_node maps data for nodes crossed by the selection boundary, while owned_node maps data for nodes wholly inside the selection. Implementations may compact both stores and thereby change hedge and node indices.
