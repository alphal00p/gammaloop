LayoutStream

linnet_py / Class

All module symbolsPython interface guideGraph algorithms workflow
LayoutStream()

A synchronous iterator that advances the native force solver in batches.

Topology is fixed for the lifetime of the stream. Frames contain only coordinates and progress, so notebook viewers can retain their SVG elements.
