Print a tagged tensor using native Typst attachments in Spenso’s Typst mode.

Every script occupies the same horizontal column in the top and bottom rows. The opposite row receives a hidden copy, following Physica’s tensor layout technique. Each representation owns its preferred row; only the dual orientation of a dualizable representation flips that row.
