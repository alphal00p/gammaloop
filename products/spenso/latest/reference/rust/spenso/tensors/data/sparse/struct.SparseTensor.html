pub struct SparseTensor<T, I = OrderedStructure> {
    pub elements: HashMap<FlatIndex, T>,
    pub zero: T,
    pub structure: I,
}
Expand description

Sparse data tensor, generic on storage type T, and structure type I.

Stores data in a hashmap of usize, using ahash’s hashmap. The usize key is the flattened index of the corresponding position in the dense tensor
