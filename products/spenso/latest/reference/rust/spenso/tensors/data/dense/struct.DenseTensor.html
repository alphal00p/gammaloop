Struct DenseTensor

pub struct DenseTensor<T, S = OrderedStructure> {
    pub data: Vec<T>,
    pub structure: S,
}
Expand description

Contiguous tensor components paired with their structural coordinate map.

data follows TensorStructure::strides, which is row-major by default: coordinates are given in external-slot order and the last coordinate varies fastest. Self::from_data validates the component count but does not permute values if the supplied structure was created from an unsorted slot list.

Fields§

§data: Vec<T>

Components in the flat order defined by structure.

§structure: S

Tensor structure that maps external slots to flat component indices.
