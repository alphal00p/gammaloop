gammaLoop integrate

CLI reference / Command

All commandsSettings namespacesEvents and observables workflow

Integrate one or more generated process integrands

Synopsis

Usage: gammaLoop integrate [OPTIONS]

Options

-p, --process

#

Process reference: #<id>, name:<name>, or <id>/<name>; repeat with -i to select multiple integrands

Behavior
accepts repeated values; 1 value(s)
Value names
PROCESS

-i, --integrand-name

#

The integrand name to integrate; repeat with -p to select multiple integrands

Behavior
accepts repeated values; 1 value(s)
Value names
NAME

-c, --n-cores

#

Number of cores to parallelize over

Behavior
sets one value; 1 value(s)
Value names
N_CORES

-w, --workspace-path

#

Workspace directory used for resumable integration state and persisted results

Behavior
sets one value; 1 value(s)
Value names
WORKSPACE_PATH

-t, --target

#

Specify a target as either re im / re,im for one shared target or process@integrand=re,im

Behavior
accepts repeated values; 1–2 values
Value names
TARGET

-r, --restart

#

Whether to restart the integration from scratch, or continue from a previous run if possible

Behavior
sets true; no value
Default
false

--uncorrelated

#

Use one independent sampling/training grid per selected integrand instead of a shared grid

Behavior
sets true; no value
Default
false

--show-max-weight-info

#

Show the overall max-weight details table

Behavior
sets true; no value
Default
true

--no-show-integration-statistics

#

Hide integration statistics during intermediate iteration updates

Behavior
sets true; no value
Default
false

--show-phase

#

Control which complex phase is shown in integration summary tables

Behavior
sets one value; 1 value(s)
Value names
SHOW_PHASE
Default
both
Values
both, real, imag, selected

--show-top-discrete-grid

#

Show monitoring rows for the first non-trivial discrete dimension

Behavior
sets true; no value
Default
false

--show-discrete-contributions-sum

#

Show the summed discrete contributions block independently of per-bin rows

Behavior
sets true; no value
Default
false

--sort-contributions

#

Sort discrete contribution rows by index, absolute integral, or error

Behavior
sets one value; 1 value(s)
Value names
SORT_CONTRIBUTIONS
Default
error
Values
index, integral, error

--show-max-weight-info-for-discrete-bins

#

Show per-bin max-weight information for the first non-trivial discrete dimension

Behavior
sets true; no value
Default
false

--show-summary-only

#

Only render the saved integration summary, without performing integration work

Behavior
sets true; no value
Default
false

--no-stream-iterations

#

Disable streaming of end-of-iteration integration summaries in interactive terminals

Behavior
sets true; no value
Default
false

--no-stream-updates

#

Disable live streaming of in-iteration integration status updates

Behavior
sets true; no value
Default
false

--renderer

#

Renderer used for interactive streaming integration updates

Behavior
sets one value; 1 value(s)
Value names
RENDERER
Default
ratatui
Values
tabled, ratatui

--batch-size

#

Evaluate each iteration in per-core batches of this size

Behavior
sets one value; 1 value(s)
Value names
BATCH_SIZE

--batch-timing

#

Target per-core batch wall time in seconds when batch size is not specified

Behavior
sets one value; 1 value(s)
Value names
BATCH_TIMING
Default
5

--min-time-between-status-updates

#

Minimum time between streamed in-iteration status updates

Behavior
sets one value; 1 value(s)
Value names
MIN_TIME_BETWEEN_STATUS_UPDATES
Default
0

--max-table-width

#

Maximum width used when normalizing integration status tables

Behavior
sets one value; 1 value(s)
Value names
MAX_TABLE_WIDTH
Default
250

--write-results-for-each-iteration

#

Keep per-iteration result and observable snapshot files in addition to the latest snapshots

Behavior
sets true; no value
Default
false

Print help
