gammaLoop approach

CLI reference / Command

All commandsSettings namespacesSample evaluation contractConfiguration and diagnostics guide

Sample an integrand while approaching a phase-space point along selected scaling axes

Synopsis

Usage: gammaLoop approach [OPTIONS] --n-points <N>

Command hierarchy

ParentgammaLoop

Arguments and options

Options

  • -p, --processProcess reference: #<id>, name:<name>, or <id>/<name>optional
  • -i, --integrand-nameThe integrand name to approachoptional
  • -x, --pointIntegration coordinates, or flattened loop momenta (px, py, pz) ... with --momentum-spaceoptional
  • --approach-axisDirection vector in the same coordinate layout and dimension as --pointoptional
  • --n-pointsNumber of points on each side of the midpointrequired
  • --linearUse linear spacing in toptional
  • --logarithmicUse logarithmic spacing in |t|optional
  • --min-abs-tSmallest non-zero |t| for logarithmic spacingoptional
  • --n-coresNumber of worker threads for approach evaluationsoptional
  • -f, --use_arb_precForce arbitrary-precision (Arb) internal evaluation; results remain f64optional
  • -m, --momentum-spaceInterpret --point and every axis as spatial loop-momentum tripletsoptional
  • -d, --discrete-dimThe discrete dimensions of the sampleoptional
  • --graph-idSelect a specific graph in momentum-space approachoptional
  • --orientation-idSelect a specific orientation of the selected graph in momentum-space approachoptional
  • --output-resultsWrite sampled approach points and run metadata to this JSON fileoptional
  • -h, --helpPrint helpoptional
