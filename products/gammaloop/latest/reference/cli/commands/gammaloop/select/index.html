gammaLoop select

CLI reference / Command

All commandsSettings namespacesUsing GammaLoop from the command line

Select graph groups and write the selection to a new process or integrand

Synopsis

Usage: gammaLoop select [OPTIONS]

Command hierarchy

ParentgammaLoop

Arguments and options

Options

  • -p, --processProcess reference: #<id>, name:<name>, or <id>/<name>optional
  • -i, --integrand-nameIntegrand name inside the selected processoptional
  • --amplitude-graphsApply structural filters to left/right amplitude graphs of cross-section cutsoptional
  • --with-graph-namesRetain graph groups with these master graph namesoptional
  • --with-only-graph-namesRetain exactly these graph groups and ignore every other selection filteroptional
  • --without-graph-namesRemove graph groups with these master graph namesoptional
  • --with-raised-propagator-signaturesRetain graph groups with one of these raised-propagator signaturesoptional
  • --without-raised-propagator-signaturesRemove graph groups with one of these raised-propagator signaturesoptional
  • --with-massive-raised-propagator-signaturesRetain graph groups with one of these massive raised-propagator signaturesoptional
  • --without-massive-raised-propagator-signaturesRemove graph groups with one of these massive raised-propagator signaturesoptional
  • --with-massless-raised-propagator-signaturesRetain graph groups with one of these massless raised-propagator signaturesoptional
  • --without-massless-raised-propagator-signaturesRemove graph groups with one of these massless raised-propagator signaturesoptional
  • --with-raised-cuts-signaturesRetain graph groups where a process-valid cut touches one of these raised-propagator group signaturesoptional
  • --without-raised-cuts-signaturesRemove graph groups where a process-valid cut touches one of these raised-propagator group signaturesoptional
  • --with-massive-raised-cuts-signaturesRetain graph groups where a process-valid cut touches one of these massive raised-propagator group signaturesoptional
  • --without-massive-raised-cuts-signaturesRemove graph groups where a process-valid cut touches one of these massive raised-propagator group signaturesoptional
  • --with-massless-raised-cuts-signaturesRetain graph groups where a process-valid cut touches one of these massless raised-propagator group signaturesoptional
  • --without-massless-raised-cuts-signaturesRemove graph groups where a process-valid cut touches one of these massless raised-propagator group signaturesoptional
  • --with-cycle-signaturesRetain graph groups matching one of these cycle signaturesoptional
  • --without-cycle-signaturesRemove graph groups matching one of these cycle signaturesoptional
  • --with-verticesRetain graph groups containing at least one of these vertex-rule multisetsoptional
  • --without-verticesRemove graph groups containing at least one of these vertex-rule multisetsoptional
  • --with-particlesRetain graph groups containing all particles from at least one of these particle setsoptional
  • --without-particlesRemove graph groups containing all particles from at least one of these particle setsoptional
  • --output_processCopy the selected graph groups to this output process instead of modifying in placeoptional
  • --output_integrandCopy the selected graph groups to this output integrand instead of modifying in placeoptional
  • -c, --clear-existing-processesAllow copy-mode selection to replace an existing output process or integrandoptional
  • -h, --helpPrint helpoptional
