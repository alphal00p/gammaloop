Positional arguments

tokens

#

Quote-free spec.

Grammar (unquoted): INITIAL to FINAL [process_options] [generation_options] Also accepts: INITIAL > FINAL [ ... ]

Examples: e+ e- to d d~ g veto u d xs QED^2==2 QCD^2<=4 pert loops=1 fsloops=2 QCD=2 e+ e- > { z z, a a } [ {1} {{2}} QCD=2 QED=1 ] / u d | g ghG QED==2 QCD>=2 QCD<=4

Notes:

  • veto and only are synonyms for / and |.
  • The [ ... ] block holds perturbative spec: {n}, {{n}}, and orders QCD=n with shorthand QCD≡1.
Behavior
accepts repeated values; 1 or more values
Value names
TOKENS
