gammaLoop inspect

CLI reference / Command

All commandsSettings namespacesEvents and observables workflow

Inspect integrand contributions at one phase-space point or momentum configuration

Synopsis

Usage: gammaLoop inspect [OPTIONS]

Command hierarchy

ParentgammaLoop

Arguments and options

Options

  • -p, --processProcess reference: #<id>, name:<name>, or <id>/<name>optional
  • -i, --integrand-nameThe integrand name to inspectoptional
  • -x, --pointThe point to inspect (x y) or (p0 px ...)optional
  • -f, --use_arb_precEvaluate in f128 precisionoptional
  • -m, --momentum-spaceInterpret point as momentum-space coordinatesoptional
  • -d, --discrete-dimThe discrete dimensions of the sampleoptional
