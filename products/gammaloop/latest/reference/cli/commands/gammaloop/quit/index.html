gammaLoop quit

CLI reference / Command

All commandsSettings namespacesUsing GammaLoop from the command line

End the interactive GammaLoop session without executing further commands

Synopsis

Usage: gammaLoop quit [OPTIONS]

Command hierarchy

ParentgammaLoop

Arguments and options

Options

  • -p, --pathPath to save the state to, by default is the current state folderoptional
  • -o, --override-stateSave state to file after each calloptional
  • -n, --no-save-stateExit without writing state data, even when state saving is otherwise enabledoptional
  • --try-stringsTry to serialize using strings when saving run historyoptional
  • --strictTreat state serialization warnings as errors and refuse a partial saveoptional
  • -h, --helpPrint helpoptional
