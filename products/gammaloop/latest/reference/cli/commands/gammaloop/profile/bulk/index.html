gammaLoop profile bulk

CLI reference / Command

All commandsSettings namespacesConfiguration and diagnostics guide

Probe multiple infrared scaling limits and report their fitted behavior in one run

Synopsis

Usage: gammaLoop profile bulk [OPTIONS]

Command hierarchy

ParentgammaLoop profile

Arguments and options

Options

  • -p, --processProcess reference: #<id>, name:<name>, or <id>/<name>optional
  • -i, --integrand-nameThe cross-section name to inspectoptional
  • --n-pointsNumber of scaling points to sampleoptional
  • --min-scalingStarting exponent of the sampled bulk scaling rangeoptional
  • --max-scalingEnding exponent of the sampled bulk scaling rangeoptional
  • --seedRandom seed for momentum samplingoptional
  • -o, --outputOutput file for results (optional)optional
  • -s, --selectrestrict test to particular graphs or limitsoptional
  • --per-orientationProfile each visible orientation separately and report one row per orientationoptional
  • --show-per-cut-infoRetain generated event data so per-cut IR fits can be computed and displayedoptional
  • -h, --helpPrint helpoptional
