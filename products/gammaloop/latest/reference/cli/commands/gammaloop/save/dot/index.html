gammaLoop save dot

CLI reference / Command

All commandsSettings namespacesProcess generation workflow

Export generated graphs as DOT files and drawing templates

Synopsis

Usage: gammaLoop save dot [OPTIONS] [PATH]

Command hierarchy

ParentgammaLoop save

Arguments and options

Positional arguments

  • pathDestination directory; defaults to the active state folderoptional

Options

  • -cCombine diagrams in one DOT output instead of writing one file per graphoptional
  • -n, --with-uvInclude ultraviolet counterterm graphs in the exported drawing dataoptional
  • -u, --output-full-numeratorExport the full numerator expression rather than the compact display formoptional
  • -g, --do-gamma-algebraSimplify gamma-matrix algebra before formatting graph numeratorsoptional
  • --do-color-algebraSimplify color algebra before formatting graph numeratorsoptional
  • --split-xs-by-initial-statesWrite separate cross-section drawings for distinct initial-state assignmentsoptional
  • --include-autogenerated-fieldsInclude fields generated internally rather than supplied by the source graphoptional
  • -h, --helpPrint helpoptional
