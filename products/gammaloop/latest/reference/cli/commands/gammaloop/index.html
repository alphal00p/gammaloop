gammaLoop

CLI reference / Command

All commandsSettings namespacesUsing GammaLoop from the command line

An implementation of the Local Unitarity method for computing differential collider cross-sections.

Synopsis

Usage: gammaLoop [OPTIONS] [BOOT_COMMANDS_PATH] [COMMAND]
