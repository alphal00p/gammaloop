gammaLoop display model

CLI reference / Command

All commandsSettings namespacesCreate your first state

Show model particles, parameters, couplings, and vertices for the selected context

Synopsis

Usage: gammaLoop display model [OPTIONS]

#

Include the model's coupling-order definitions and coupling values

sets true; no value
Default
false

sets true; no value

false

sets true; no value
Default

false
