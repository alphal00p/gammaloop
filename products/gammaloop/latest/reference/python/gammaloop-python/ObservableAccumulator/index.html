ObservableAccumulator

gammaloop / Class

All module symbolsPython interface guideEvents and observables workflow
ObservableAccumulator()

Independent observable statistics compiled from one integrand's definitions.

Construct with api.observable_accumulator() and add exactly one evaluation record per independent draw. The coefficient is the complete outer weight; zero keeps the attempted sample count without fills. Event groups stay unmodified.

Examples

accumulator = api.observable_accumulator()
batch = api.evaluate_samples(points)
for sample in batch.samples:
    accumulator.add_sample(sample, sample.integrator_weight)
histograms = accumulator.snapshot()
