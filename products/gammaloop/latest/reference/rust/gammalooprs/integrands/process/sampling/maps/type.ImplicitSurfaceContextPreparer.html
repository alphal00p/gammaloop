Expand description

Complement-only centre and existence classification of a directional chart.

The context is the output of an earlier ordered map (typically a sampled complement block). Keeping this preparation separate from the scalar surface evaluator makes the dependency explicit: derivatives with respect to the active radial coordinates remain block diagonal, while centre and root changes with the complement occupy only the off-diagonal Jacobian block. The vector has the active dimension and is passed to each radial equation evaluation, so an optimizer is never invoked inside the root solve.
