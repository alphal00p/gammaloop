Expand description

Resolution of user-facing graph sampling channel selections.

Settings deliberately keep selectors as strings so that TOML and Python have the same compact interface. This module turns those strings into a typed, deterministic selection after the graph name is known. Numerical channel construction is intentionally kept out of this layer.
