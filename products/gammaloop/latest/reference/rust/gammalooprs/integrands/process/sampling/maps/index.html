Symbolica-validated descriptions of graph-aware sampling maps.

The graph-independent map language and the reusable ordinary-map numerical kernel live here. Graph-aware surface and cut maps are compiled by the process layer. Parsing is structural: a complete Symbolica expression is checked recursively, so a valid nested call cannot hide an invalid root or sibling.

SamplingMapContextTransform
A product or ordered map whose child output blocks are embedded into an explicitly supplied master-frame permutation. This is the exact generic construction used for a surface subspace together with its complement: each child remains in its native coordinates, while this wrapper only permutes complete three-momentum blocks. The permutation has unit absolute determinant, so the product Jacobian is unchanged. A conditional frame transform first prepares the actual preceding outputs, then converts the active physical output back to raw coordinates with its exact determinant.
