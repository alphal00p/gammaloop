fn from_arb(value: &ArbPrec) -> Self

Round directly from the canonical Arb draw, never through another lane. Materialization uses the checked F::from_arb boundary below.

Source

fn mpfr_enclosure(&self, precision: u32) -> (Float, Float)

Enclose the exact represented native value at the requested MPFR precision. Directed rounding includes both separated Quad limbs; this is a certificate boundary, unlike ordinary nearest-rounded conversion.

Source
