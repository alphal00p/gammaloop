# Golden data

Frozen copies of the supporting material of the report "One-loop renormalisation of the Standard Model with a
non-anticommuting gamma5" (one family, unbroken phase, BMHV). Tests read only these files, never the originals.
Paths are relative to `one_loop_explicit_calculation/` of the gamma5 project; all copies were made on 2026-11-28.

The digest was written by `SCRATCHPAD/automation/ms1_core/make_digest.py`: it replaces the Lorentz-structure and
coupling names of each vertex rule by their definitions and keeps leg order, colour structures and coupling
orders. Conventions of the hand-written model (`SCRATCHPAD/model/README.md`): leg `k` of a rule is
`particles[k-1]`, `P(idx, k)` is the incoming momentum of leg `k`, a coupling is `i` times the coefficient in the
Lagrangian, SU(2) and the ghosts/sources are encoded in components with `ghost_number` 0, `bmhv::bar` /
`bmhv::hat` mark four-dimensional / evanescent Lorentz indices.

Naming in `final_counterterms.json`: couplings `g_s`, `g`, `gp` (= g'), `y_u`, `y_d`, `y_e`, `lambda`, `m2`;
the monomials carry the engine names of `SCRATCHPAD/st/bases.py` and `bases_n.py` and the typst names of the
report (tab:Qbasis, tab:Nbasis).
