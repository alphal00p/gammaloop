# spenso-macros

This crate provides procedural macros for defining custom index representations in the Spenso
ecosystem. Use the canonical [Spenso interface guide](https://alphal00p.github.io/gammaloop/products/spenso/latest/reference/interfaces/)
for supported macro boundaries and the native
[`SimpleRepresentation` Rustdoc](https://alphal00p.github.io/gammaloop/products/spenso/latest/reference/rust/spenso_macros/derive.SimpleRepresentation.html)
for exact attributes and targets.
