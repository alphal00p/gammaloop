# Spenso high-energy-physics tensor library

This crate provides gamma matrices, projectors, and other high-energy-physics tensor definitions
for Spenso networks parsed from Symbolica expressions. The canonical overview and workflows are
in the [Spenso tensor-network guide](https://alphal00p.github.io/gammaloop/products/spenso/latest/guides/networks/); use the
[native Rustdoc](https://alphal00p.github.io/gammaloop/products/spenso/latest/reference/rust/spenso_hep_lib/)
for exact signatures at the documented revision.
