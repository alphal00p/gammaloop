The `five_loop_q0` directory contains the exact retained result and checked
300-digit scalar coefficients of formal master products through ε⁵. No master
values are substituted. Native Atom and exact-ratio JSON are lossless; numerical
`.expr` files are displays.

See [the conventions and commands](../../docs/five_loop_q0_coefficients.typ) and
[the companion example](../five_loop_q0_coefficients.py).
