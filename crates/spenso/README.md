# Spenso

Spenso provides typed tensor structures and data, automatic contractions, executable tensor
networks, and Symbolica interoperability.

Use the canonical [Spenso overview](https://alphal00p.github.io/gammaloop/products/spenso/latest/),
[first contraction tutorial](https://alphal00p.github.io/gammaloop/products/spenso/latest/tutorial/), and
[tensor-network guide](https://alphal00p.github.io/gammaloop/products/spenso/latest/guides/networks/) for maintained workflows.
Use the [native Rustdoc](https://alphal00p.github.io/gammaloop/products/spenso/latest/reference/rust/spenso/)
for exact signatures at the documented revision. Contributor policy is in
[`CONTRIBUTING.typ`](../../CONTRIBUTING.typ).
